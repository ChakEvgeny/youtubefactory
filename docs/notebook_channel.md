# Survivor's Notebook — как делать ролики канала

Канал `@SurvivorsNotebook` (бывший The Long Way Back, переименован 2026-09-18).
Настоящие истории выживания, рассказанные как страницы полевого дневника.
10–20 минут, английский. Голос канала прежний — `NFG5qt843uXKj4pFvR7C`
(голос действующего канала не меняем). Первый ролик формата — «Карлук», 1914.

## Конвейер

1. Тема: `field_check.py`, три формулировки, смотреть ролики ПО ТЕМЕ, а не верх
   выдачи (у Hartzell верх — рэпер Drake).
2. `brief.json` — факты со ссылками. Ни одной цифры в сценарии без факта.
3. `script.md` — блоки `## N. NAME`. Без воды: общие фразы заменять деталями
   из источника. Спорное (уход Стефанссона) — как спор, с обеими сторонами.
4. `cast.json` — приметы повторяющихся героев + `narrator.id`.
5. `scrap_plan.json` — клочки задаются вручную (~9 на ролик), `_intro_after`,
   `_roster`. Без плана модель ставит 18 клочков, половина пустые («$10,000»).
6. `scripts/notebook_board.py` → `board.json`.
7. `scripts/notebook_scenes.py` → `scenes/` (эталон стиля `styletest/ref.jpg`).
8. `scripts/voice_blocks.py <dir> --speed 1.05` (сырой темп голоса 159 wpm).
9. `scripts/notebook_map.py` — карты по Natural Earth, не нейросетью.
10. `scripts/notebook_build.py` → `FILM_*.mp4`.
11. `make_srt.py` → `translate_subs.py` → после публикации `yt_publish.py captions` и `meta` (Studio не нужен).

## Стиль

`style.txt` проекта: страница дневника 1913 года, карандаш + сепия, бледная
акварель, ОДИН ржаво-красный акцент. Почерк — Reenie Beanie, машинопись —
Special Elite. Интро `NotebookIntro`, аутро `NotebookOutro` (пока без рамок под
плитки — `slots=false`, своих роликов мало), граница блока — `PageFlip`,
инфографика — `Scrap` (клочок бумаги поверх рисунка, не отдельный экран).

## Брак, который уже ловили

- **Красный акцент на пейзаже читается как кровь.** Торос, след саней, поручень
  с ржавым мазком — 7 кадров из 129. Акцент только на отдельной ВЕЩИ; нет вещи —
  нет красного (правило вшито в `notebook_scenes.py`).
- **Метафоры рисуются буквально.** «Вскроет как консервную банку» дало банку на
  льду. Запрет в промпте раскадровки.
- **Винтовка у пустой палатки после слов о выстреле** — намёк на самоубийство,
  рекламно-чувствительно. Смерть — пустым местом, крестом вдали, предметом.
- **Клочок короче 4.5 с не прочитать** (25 имён за 2.7 с). `SCRAP_MIN`,
  после фразы тишина.
- **ffmpeg: `-t` после `-i` режет выход**, и добивка тишиной `apad` обрезается.
  Окно фразы ограничивать `-t` ДО `-i`.
- **Округление длины куска до кадра копится**: 147 кусков дали 1.9 с отставания
  картинки от голоса. Кадры куска считать от общей шкалы (`nf` в сборке).
- Natural Earth режет сушу по 180-му меридиану: шов не обводить, долготы контура
  разворачивать непрерывно (`notebook_map.py`).
- **Наложение с `-loop` даёт +1 кадр** на куске с перетеканием: число кадров задавать `-frames:v` явно.

## Смерти и ad-safety

Смерти — крестики-могилки в списке экипажа (клочок `roster`, накапливается от
клочка к клочку), пропавшие — ржавый «?». В кадре — пустая палатка, холмик с
крестом вдали, шарф во льду. Никогда тел, ран, крови, оружия рядом с погибшим.

## Выпуск (общий для всех каналов, см. CLAUDE.md «Действующие каналы»)

- Обложки: 8 вариантов, `thumbs.py --theme page --font ~/.fonts/ReenieBeanie.ttf`,
  надпись одной строкой, цепляющая. Бледная страница лежит на тёмном фоне —
  иначе сливается с белой лентой YouTube.
- `release_pack.py` → `release.txt` — всё для загрузки одним файлом.
- После загрузки: `yt_publish.py captions survival <id> <папка> --only-missing` и `meta`.
- Потом `archive_project.py <папка> --yes` → NAS.

Вышло в формате дневника: «Карлук» 1914, Бейли 117 дней (1973), тетрадь Пеглара
(Франклин, ДНК 2026). Раньше, в старом формате: Ада Блэкджек, Проспери.

## Кадр по смыслу, а не по словам

**Перед раскадровкой читать `docs/frame_meaning_rules.md`** — общее правило для
всех каналов: кадр показывает место, где мысль происходит, а не иллюстрирует её
предметом-символом; описания кадров пишутся сквозняком с учётом контекста, а не
отдельным вызовом модели по куску озвучки.


## Формат сценария

Сценарий пишется **покадрово** в `script.txt`: на каждый шот `[номер] KIND`,
`EN:`, `RU:`, `КАДР:`. Блоки — `═══ БЛОК N · НАЗВАНИЕ ═══`. Общее правило всех
каналов, см. CLAUDE.md, раздел «Формат сценария». Прежний формат прозой
(`script.md`) не использовать: по нему нельзя принять раскадровку до генерации.
