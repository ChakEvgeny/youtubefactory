# Ниши под простую рисованную графику (замер 2026-09-10)

Метод: 12 ниш-кандидатов × 3 запроса × 3 прохода (120 дн medium, 365 дн long, 365 дн medium) через yt-dlp;
Data API только для channels/videos.list (108 units). Разметка релевантности и визуального формата — Opus 5
по 3 549 роликам ($1.65). 47 каналов-кандидатов профилированы: последние 25 роликов (yt-dlp), дата создания
(Data API), стиль по трём обложкам (Opus vision), воспроизводимость нашим 2D-конвейером 1–5 ($1.2).
Скрипты: `scripts/niche_animated.py`, `scripts/channel_profile.py`; данные — `/mnt/d/youtube/cache/niche_animated.json`,
`/mnt/d/youtube/cache/channel_profiles/`.

Критерий «взлетел»: канал моложе 30 мес, ≥30k подписчиков, стиль simple_2d/stickman/whiteboard, медиана
просмотров последних 25 роликов и v/s (медиана/подписчики) — как подтверждение, что рост не на Shorts.

## Вывод

Самая крепкая по данным — психология (4 канала ≥200k за ≤28 мес, лучший RPM). История — самый живой
приток новичков (два канала младше 5 месяцев). Животные — один лидер с медианой 1.1M и слабые клоны:
ниша открыта, но формат держится на юморе сценария Dinzo, а не на графике.

Что нужно от конвейера для всех трёх: иллюстрации в едином плоском стиле (персонаж + 2–3 позы + фон),
Remotion-анимация «вырезки на слоях» (parallax, покачивание, появление), выразительный голос с юмором,
project pack для ручной правки. Псевдореализм — нет.
