## Что изменилось 2026-09-18…19 (главное)

1. **Фотореалистичные фильмы с Veo остановлены.** Причины: цена (по счёту Google
   ~€67 за фильм против $31–43 в нашем журнале), 45% брака на клипах, органический
   CTR 0% у 4 фильмов из 5.
2. **Оба сюжетных канала пересобраны в рисованных форматах** с сохранением тем:
   выживание — страницы дневника 1913 года (перо, штриховка, красная полоса у края
   листа), криминал — нуар-комикс с ризографом. Один параметрический конвейер
   (`format.json` + `build.json` на канал) обслуживает оба; Veo и DepthFlow не
   используются. Эталон качества сборки — Why&How.
3. **Каналы переименованы и перебрендированы:** интро (перелистывание страницы /
   «три панели»), аутро «The End» без рамок под конечную заставку, баннер, иконка,
   описание, теги. Заставка канала ставится **после хука**.
4. **Публикация субтитров и переводов переведена на API** (Studio ломался):
   `make_srt.py` → `translate_subs.py` (es-419, pt-BR, de, fr) → `yt_publish.py
   captions ... --only-missing` и `meta`. Английскую дорожку автор заливает сам —
   не перезаписывать. Приложение OAuth выведено In production (бренд-аккаунты в
   режиме Testing получали 403).
5. **Статистика — через Analytics API** (`scripts/yt_stats.py`), больше не
   скриншотами Studio. Показы и CTR значка Analytics API не отдаёт — они только в
   Reporting API, он не включён (это незакрытый хвост).
6. **Обложки переделаны полностью** — см. ниже.

## Обложки (разбор 2026-09-19)

Повод: CTR 0,6–0,8% при норме 2–6%; единственная рабочая обложка — Larson, 7,7%.

рисует код, автопроверка Opus на 210×118. Правила — `docs/thumbnail_standard.md`,
скрипты `scripts/thumbs_v2.py` (генерация) и `scripts/thumbs_fix.py` (перекладка
готовых фонов без генерации). Евгений выбрал варианты и **уже заменил обложки на
YouTube**. Пачка на NAS: `/mnt/nas/output/_thumbs/2026-09-19_work` и `_ready`, на

Выводы, которые вошли в правила: число в обложке выигрывает почти всегда; где

на кадре с тёмной подложкой); раскладок ровно три.

## Метрики, по которым судим

Пороги из `CLAUDE.md` не менялись: CTR ≥ 4%, удержание на 30-й секунде ≥ 60%,
среднее удержание ≥ 40%; засчитывается, если порогам отвечают хотя бы 2 ролика из 5.
Неделя 12 — 1000 подписчиков и рост просмотров неделя к неделе.

Ближайшая проверка — обложки: они заменены 2026-09-19, сравнивать CTR до и после
по `scripts/yt_stats.py`, когда появятся показы (Analytics отстаёт на 1–3 дня, а
сами показы придут только из Reporting API).
