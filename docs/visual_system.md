# Визуальная система: что мы можем себе позволить

Замер 2026-09-11 по двум референсам, скачанным для анализа.
Инструмент — `scripts/autopsy_rhythm.py` плюс контактные листы.

## Что делает Atlas One (967k, выживание)

| параметр | значение |
|---|---|
| длина | 21:38 |
| жёстких склеек за весь ролик | **0** |
| переходы | только перетекания (dissolve) |
| кадров в минуту (счёт по контактному листу) | ~11, то есть 5–6 с на кадр |
| статики с наездом | практически нет, движется каждый кадр |
| стиль | фотореализм, сгенерированный целиком |

Главное — не стиль, а **как они прячут слабости генерации**. Разобрал кадры:

- лица в кадре либо отсутствуют, либо крошечные на общем плане, либо
  повёрнуты и перекрыты движением (брызги, дым, ветка);
- очень много планов **только с руками**: руки над углями, руки с верёвкой,
  руки в песке. Лица нет вообще, а действие читается;
- много кадров **вообще без людей**: проём, море, обломок, костёр, текстура;
- ни одной сцены с чтением, письмом, вывеской или цифрой.

Перетекания вместо склеек — тоже маскировка: на растворении глаз не успевает
поймать несостыковку между кадрами.

## Что делает PLAN: ESCAPE (695k, побеги)

| параметр | значение |
|---|---|
| длина | 19:17 |
| кадров | 349, это 18.1 в минуту |
| медиана кадра | 3.0 с (p10 1.5, p90 5.5) |
| доля кадров с движением | 0.67 — то есть **треть кадров статична** |
| переходы | 90% жёсткая склейка, 10% мягкая |

Другая школа: вдвое чаще режет, треть кадров — статичные картинки и карты,
и есть вставки с ведущим в кадре. Ведущий нам не подходит, канал безликий.

## Вывод для ролика про Аду

Стиль первого нашего фильма сюда не годится: там был павильон, суд, бумаги.
Здесь нужна фактура Арктики. Но полный фотореализм с лицами нам не нужен и
не по деньгам. Берём **систему Atlas One без её слабого места** — то есть
фотореалистичную генерацию, где лицо героини почти никогда не в кадре.

Это не компромисс, а совпадение с форматом: у нас и так правило «роль вместо
имени», и Ада должна быть фигурой, а не портретом.

### Бюджет кадров на 21 минуту, около 230 кадров

| тип | доля | чем делаем | почему |
|---|---:|---|---|
| движущийся клип | 40% | Veo 3.1 **fast**, 4 с, 720p | руки, снег, капкан, лодка, ветер |
| статика с медленным кропом | 35% | Gemini image + наш `fx_filter` | пейзаж, предмет, текстура, палатка |
| карты и схемы | 15% | рисуем сами | остров, маршрут троих по льду, расстояния |
| карточки с текстом | 10% | PIL | даты, цифры, строки дневника |

Ни один кадр с текстом не отдаётся нейросети — правило уже в `block_build.py`.

Против примерно $480 генерации на первом фильме. Разница берётся из трёх
решений: fast вместо standard ($0.10 против $0.40 за секунду), четыре секунды
вместо шести-восьми, и отказ от кадров с текстом, которые давали больше
половины перегенераций.

### Что даёт архив

История 1921–1923 годов. Существуют подлинные фотографии экспедиции и дневник
Ады в библиотеке Дартмутского колледжа. Это бесплатный материал, который
одновременно поднимает доверие и закрывает самый дорогой для генерации тип
кадра — портрет реального человека. Перед использованием каждый файл проверяем
по лицензии отдельно и указываем источник в описании.

## Для ролика про Ларсона

Тут наоборот: стиль первого фильма подходит полностью. Гостиная 1984 года,
телевизоры, кассеты, студия телеигры. Единственная новая задача — световое
табло, и его мы рисуем сами в PIL, кадр за кадром, потому что нейросеть
никогда не нарисует одинаковую сетку дважды.
