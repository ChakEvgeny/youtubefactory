## Что конкретно берём

### remotion-motion-graphics — главная находка

Прямо отвечает на претензию «уёбанская анимация». Десять правил, каждое бьёт
по нашему коду:

1. **Никакой линейной интерполяции.** Каждый `interpolate()` с easing, каждое
   появление через `spring()`, всегда `extrapolateLeft/Right: "clamp"`.
   У нас сейчас линейные `interpolate` в `Chart` и `Counter`.
2. **Появление анимирует 2–3 свойства сразу** (opacity + translateY + scale).
   Одиночный fade запрещён. У нас в `Callout` только scale+opacity.
3. **Стаггер всего**: списки, слова, карточки — сдвиг 3–6 кадров.
4. **Уходы существуют и быстрее появлений** (~10 кадров против ~20).
   У нас уходов нет вообще — клип просто обрывается.
5. **Пятислойный стек в каждой сцене**: фон-меш → ассеты → графика/типографика →
   цветокоррекция → зерно и виньетка. Никакого плоского фона.
   У нас плоская заливка `bg` — отсюда ощущение дешевизны.
6. **Ken Burns на каждом стоп-кадре**, `<OffthreadVideo>` вместо `<Video>`.
7. **Простаивающие элементы дышат**: всё, что на экране дольше 2 с, получает
   микродвижение по синусоиде.
8. Тайминги только через `useVideoConfig()`, магических чисел кадров нет.
9. **Одна тема** на проект: цвета, easing, пресеты пружин, шрифты.
10. **Отрендерить → достать кадры → посмотреть → починить.** Обязательный цикл.

### vt-remotion — переходы

`lib/transitions/` и `TransitionSeries` поверх `@remotion/transitions`.
Компоненты `SlideTransition` (fade / zoom / slide-up / blur-fade) и `Vignette`.
Отсюда берём dip-to-black между главами и push-in на цифрах.

### vt-ffmpeg — рецепты

Флаги для совместимости (`-movflags faststart`, `-pix_fmt yuv420p`,
`scale=trunc(iw/2)*2`), извлечение аудио, сжатие. Пригодится для J/L-cut
и speed-ramp.

### vt-elevenlabs — важное уточнение по моделям

Таблица скилла говорит прямо: **`eleven_v3` — alpha, ненадёжна, требует
подбора промпта**, SSML-теги (`<break>`, `<phoneme>`) она **не поддерживает**;
их держат только `flash`/`turbo`. Квадратные аудио-теги (`[thoughtful]`) —
отдельный механизм v3, его и проверяем замером.

Music API подтверждён рабочим: `client.music.compose()`, от 10 секунд до
5 минут, `music_length_ms`.

## Ограничение remotion-production

Скилл предполагает набор MCP-серверов, которых у нас нет: **KIE** (media),
**TwelveLabs** (видеоанализ). Команда `review-video` — это и есть тот самый
«video feedback skill», но она целиком построена на TwelveLabs: индексирует
ролик у них и просит разбор.

**Вывод: как есть не работает.** Но идея верная, и у нас уже есть дешёвая
замена — Haiku vision, которым мы отбираем сток и проверяем читаемость обложек.
Свой цикл обратной связи собираем так: достать кадры из `video.mp4` каждые
N секунд → отдать сеткой в Haiku vision вместе с текстом сценария на этом
участке → получить замечания по ритму, соответствию и композиции. Стоит
центы вместо подписки на TwelveLabs.

## Чего в скиллах нет

Ни один не решает наши задачи по источникам кадров: editorial-пресс-киты,
Wikimedia/Flickr CC, fair-use фрагменты новостей. Это пишем сами.
