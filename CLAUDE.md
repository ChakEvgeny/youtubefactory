# YouTube Faceless Video Factory

Фабрика безликих YouTube-роликов. Ролики **не на русском**: целевой язык и ниша
выбираются по данным YouTube Data API v3, а не по интуиции.

**Конвейер:** факты → сценарий → раскадровка (Opus) → рисунки (Gemini image) →
озвучка ElevenLabs блоками → сборка ffmpeg + Remotion → субтитры/переводы через API.

**Пути:** готовые ролики `/mnt/d/youtube/output/<канал>/<дата>_<тема>/`;
бэкап `/mnt/nas/output`; кэш `/mnt/d/youtube/cache`.

**Язык производства — английский.** Каналы англоязычные: промпты, описания
кадров, названия блоков, подписи контактных листов, поля раскадровки — всё
по-английски (решение Евгения 2026-09-23). Русский только для субтитров,
переводов метаданных и разговора с Евгением. Подробности —
`docs/frame_meaning_rules.md`.

**Секреты:** все ключи только в `.env` — никогда не коммитить в git и никогда
не копировать на NAS.

**Supabase:** хранилище кэша ответов API и очереди тем.

**Квота Data API:** 10 000 units/день, `search.list` = 100 units. Все результаты
`search.list` сохранять в Supabase; перед вызовом проверять кэш, запросы не повторять.

**Жёсткие правила производства (для всех каналов):**
- **Факты — до сценария.** Под каждую тему собирать 40–60 фактов с URL
  (`brief.json` + `facts_extra.md`), конфликты источников помечать. В сценарии
  ни одной фразы без источника; «для атмосферы» не дописывать. Спорное — без
  спорной цифры или как спор. Живые не осуждённые люди — только факты суда и их
  собственные слова (Knoedler: Фридман не обвинялась).
- **Без воды, но и не куце.** Длина следует фактам, однако **нижняя граница —
  6–8 минут** (решение Евгения 2026-09-23). Сценарий вышел короче — тему
  расширяем; расширить без воды нельзя — **меняем тему**, а не разбавляем.
  Общие фразы заменять деталями. Считать по замеру речи: 177 слов в минуту
  на скорости 1.2, то есть 6 минут ≈ 1060 слов, 8 минут ≈ 1420.
- **Тема:** `field_check.py`, три формулировки, вердикт по верхнему ролику
  ИМЕННО ПО ТЕМЕ (читать строки, не общий вердикт скрипта). Заголовок — с
  поисковой сущностью (имя, место, год, компания).
- **Инфографика — вручную по плану** (`scrap_plan.json`, 7–9 штук на ролик), не
  отдельным экраном, а предметом поверх кадра. Без плана модель лепит лишние.
  Все числа на карточках — из брифа. **Карта в кадре рисуется, а не вставляется**
  (решение Евгения 2026-09-24): `notebook_map.py` по Natural Earth даёт настоящую
  геометрию, этот png идёт в `ref` кадра строкой, и модель перерисовывает его в
  стиле канала — берега и положение всего на карте сохраняются, меняется только
  манера. Готовый png в ролик не кладётся: печатная карта выпадает из дневника.
  Маленькая карта-карточка поверх кадра (`scrap` типа `map`) — другое дело, она
  остаётся как есть.
- **Кадр следует истории блока, а не существительному из фразы** —
  `docs/frame_meaning_rules.md`. У блока пишется `thread` (кто герой кадров и
  что с ним происходит), каждый кадр — состояние этой линии. Аналогия занимает
  один кадр, второй раз только колбэком. До и после генерации — пересказ
  истории блока по одним описаниям и по одним картинкам.
  Общее для всех каналов: не иллюстрировать реплику предметом-символом (весы,
  песочные часы, лестница), а показывать место, где мысль происходит. Описания
  кадров пишутся сквозняком с учётом соседей, а не отдельным вызовом модели по
  куску озвучки: так из 70 кадров 49 вышли браком.
- **Проверка кадров глазами** (контактный лист `qc_1.jpg`) до сборки. Брак,
  который уже ловили: акцентный цвет на льду/поверхности читается как кровь;
  метафора нарисована буквально; кости и останки в кадре; нож/оружие рядом с
  погибшим; «деревянный плот» вместо надувного; пустые поля вместо кадра.
- **Смерть не показываем:** пустая палатка, крест вдали, предмет. Кости,
  останки, каннибализм, самоповреждение — никогда, ни в кадре, ни на обложке.
- **Интро канала сразу после хука; аутро — просто «The End»**, без рамок под
  конечную заставку, пока своих роликов мало.
- **Обложки — по эталону `docs/thumbnail_standard.md`** (разбор Larson, CTR 7,7%):
  один объект крупно (≥ трети кадра, у Why&How ~половина), тёмная зона под текстом,
  3–4 слова, заглавная ≥ 90 px, 1–2 строки, без подписей вторым уровнем; внутри
  канала один шрифт/палитра/место текста. **Где есть подтверждённое число — ставить
  число и делать его крупным элементом** («117 DAYS», «$110,237», «40x»); где сюжет
  про человека — человек или лицо крупно, а не только предмет. Раскладки только три:
  колонка, число-герой, текст во всю ширину снизу. У Why&How кремовой плашки под
  текстом нет — текст на кадре с тёмной полупрозрачной подложкой. Генерация —
  `scripts/thumbs_v2.py` (3 варианта на ролик + автопроверка Opus на 210×118),
  перекладка готовых фонов без генерации — `scripts/thumbs_fix.py`. Старые
  `thumbs.py`/8 вариантов — не использовать.
- **Громкость −14 LUFS** (двухпроходный loudnorm после сборки), синхрон
  проверять: видео и звук должны совпасть до 0.05 с.
- **Релиз одним файлом:** `scripts/release_pack.py` → `release.txt` (заголовок,
  2 запасных, описание с главами, теги, настройки). Отдельные файлы Евгению не
  раздавать.
- **Субтитры и переводы — через API**, не Studio: после того как Евгений залил
  ролик, `make_srt.py` → `translate_subs.py` (es-419, pt-BR, de, fr) →
  `yt_publish.py captions <канал> <id> <папка> --only-missing` и `meta`.
  Английскую дорожку автор заливает сам — не перезаписывать. Токены OAuth для
  `survival`, `heists`, `explain`, `work` лежат в `~/.config/yt/tokens/`. Квота API:
  дорожка = 400 units, не больше ~5 роликов в сутки.
- **Заголовки пишет Евгений сам** при заливке (решение 2026-09-24): наши он
  считает слабыми. Поэтому **метаданные переводятся с живого ролика, а не из
  `title_en.txt`**: `translate_subs.py <папка> <языки> <канал> <video_id>` берёт
  заголовок и описание с YouTube и предупреждает, если локальный текст разошёлся.
  Субтитры можно готовить заранее, заголовок с описанием — только после заливки.
  Дважды ловилось обратное: английский заголовок говорил одно, немецкий другое.
- **После публикации — на NAS:** `archive_project.py <папка> --yes` (сверка
  контрольных сумм, потом удаление с SSD). На SSD остаются только `brand_*`.
- **Учёт:** каждый вызов генерации пишется в `costs.jsonl`. Ролик стоит ~$15
  (рисунки ~$11, обложки ~$1, остальное — Opus и переводы).


## Порядок работы над роликом (все каналы)

Решение Евгения 2026-09-23. Двенадцать шагов, каждый со своей точкой приёмки.
Шаг не начинается, пока предыдущий не утверждён.

1. **Тема.** Подобрать по паре вариантов на каждый ролик и собрать аналитику:
   что сейчас заходит на YouTube в наших нишах. Список тем с коротким пояснением
   отдать **текстом в чат**, не файлом.
2. **Евгений утверждает тему.**
3. **Сценарий.** Сразу с разбивкой по кадрам, сразу **и на русском, и на
   английском**, обычным txt на диске.
4. **Евгений правит или утверждает сценарий.**
5. **Промпты и раскадровка.** Промпты для генерации кадров **пишет агент сам** —
   лучше потратить токены на промпты, чем потом на брак. **Отрисовка
   запускается только после прямого подтверждения Евгения** (решение
   2026-09-23): генерация стоит денег, и запускать её по своей инициативе
   нельзя — ни первый прогон, ни перерисовку.
6. **Сетка кадров** — контактный лист jpg на диске.
7. **Евгений правит или утверждает раскадровку.** Правки означают перерисовку
   **только названных кадров**, а не всего ролика заново. **Кадр, по которому
   правки нет, принят** — он помечается `approved` и не перерисовывается больше
   никогда. **Кадр с правкой, если он парный к соседнему, рисуется img2img от
   этого соседа** (поле `ref`), чтобы пара не разъехалась.
   **Утверждённые вставки не перерисовываются**: интро и аутро каналов уже
   сделаны, на раскадровке место под них просто отмечается («здесь интро»).
   Тратить генерацию на них нельзя.
8. **Озвучка.** Скорость у каждого канала своя, подобрана на опыте и **не
   меняется** (решение Евгения 2026-09-23): Why&How 1.2, Survivor's Notebook
   1.05, The Case Room 1.08, Terms of Employment 1.2 для закадрового текста и
   **1 для вставок от первого лица** (`docs/rules_terms_of_employment.md`).
   Медленный темп на сюжетных каналах — часть интонации дневника и нуара, а не
   недосмотр. Дорожка режется **кусками по смысловым блокам**, а не одним
   файлом: правка в одном блоке не должна тянуть за собой пересборку всего. Так
   уже работает `voice_blocks.py`.
9. **Сборка** — запускается **только после прямого одобрения Евгения**
   (решение 2026-09-23), как и отрисовка. Готовый файл кладётся на диск.
10. **Евгений смотрит.** Правки или «готово к публикации». После «готово» —
    комплект релиза: заголовок, описание, теги, обложки, субтитры (для личного
    канала добавляется русская дорожка).
11. **Евгений заливает ролик и английские субтитры сам**, после этого агент по
    API догружает остальные дорожки и переводы метаданных
    (`scripts/yt_publish.py captions/meta`).
12. **Раз в неделю — статистика** по уже выложенным роликам. Начинаем со
    следующей недели.

**Получив добро — доводить до конца** (решение Евгения 2026-09-23). Если
Евгений одобрил генерацию, правку или сборку, работа ведётся до готового
результата, а не до первой заминки с вопросом. Спрашивать заново — только
если меняется задача или нужен новый запуск, который он ещё не разрешал.

**В переработку — только забракованное.** Каждый раз перед запуском
проверять, что на перерисовку идут именно те кадры, которые не понравились,
а не весь ролик. Остальные помечены `approved` и не трогаются.

## Формат сценария — один на все каналы

Решение Евгения 2026-09-24. Сценарий любого канала пишется **покадрово** в
`script.txt`, а не сплошной прозой. На каждый шот четыре строки:

```
[номер] KIND
EN: текст, который идёт в озвучку
RU: перевод для сверки смысла
КАДР: что видим
```

Блоки разделяются строкой `═══ БЛОК N · НАЗВАНИЕ ═══`. Места готовых вставок
отмечаются строкой `>>> ИНТРО КАНАЛА <<<` / `>>> АУТРО КАНАЛА <<<` и не рисуются.
Карточка добавляет строку `КАРТОЧКА:` перед EN.

**Почему так.** Без `КАДР` Евгений не видит, что окажется в кадре, пока не
потрачены деньги на отрисовку; без `RU` он не может сверить смысл. Проза по
блокам (прежний формат `script.md` у Survivor's Notebook и The Case Room) годится
машине, но не человеку на приёмке — а приёмка сценария стоит раньше генерации.

Старые `script.md` остаются в проектах как `script_prose.md`, конвейер читает
`script.txt`.

## Ничего не затираем — папка archive в проекте

Решение Евгения 2026-09-24. В проекте есть папка `archive/`. Туда уходит всё,
что заменяется: неудачные кадры, прошлые версии сценариев, старые стили,
черновые сборки. **Перезаписывать поверх нельзя**, удалять — тем более.

Кадр переписывается так: старый файл переезжает в
`archive/scenes/NNN_ГГГГММДД-ЧЧММСС.jpg`, новый встаёт на его место. Это делают
сами генераторы кадров (`notebook_scenes.py`, `explain_scenes.py`,
`work_shots.py`), а не человек по памяти.

**Почему это правило.** 2026-09-24 на ZZZZ Best вся раскадровка была
перерисована поверх прежней, и прежний вариант, который Евгению нравился,
исчез без копии. Вернуть было нечем.

## Решения

**Язык: EN.** Замер 15 ниш × EN/DE показал разрыв ~39× по сумме score
(1.60B против 41M). DE проигрывает не только объёмом рынка: пять немецких
запросов вернули ноль результатов. К DE вернуться можно, но не на фазе 1.

**Три канала фазы 1** (история; пересмотрены после ручной проверки vidIQ, с 2026-09-18 заменены — см. «Действующие каналы»):

1. `business` — **основной**. `business_breakdowns`, субниша «крах европейских и
   британских брендов». **12–15 мин** (замер 2026-09-10: у Mondo ролики
   12–15 мин — медиана 290k просмотров против 14.5k у 8–12; у Logically Answered
   15–20 мин — 228k против 129k; +1–2 mid-roll). Референс формата — Mondo Startups: 8 180
   подписчиков, каналу 13 месяцев, v/s до 35. Обложка у него — стилизованный
   вордмарк бренда плюс 2–3 слова приговора, без лиц и без плашек новостных
   каналов. Сужение до Европы и UK убирает конкуренцию с индийскими каналами,
   которые держали ядро ниши в замере.
2. `space` — `space_science`, планеты и разведка миссий, 12–14 мин.
3. `disasters` — `disasters_survival`, инженерные катастрофы и отказы
   конструкций, 12–14 мин, без gore. В замере это ниша с самым высоким
   `newcomer_share` (0.48) и 7 аномалиями у молодых каналов из 13.

**`geography_maps` убран из тройки.** По цифрам ниша выглядела чисто (safe,
точность 56%, competition 3), но ручная проверка vidIQ показала, что формат
whiteboard-карт требует отдельного производственного контура, который не
переиспользуется двумя другими каналами, а `newcomer_share` 0.11 обещает
слишком медленный рост для фазы 1. Данные по нише сохранены — вернуться можно.

**`industries_inside` исключена** — см. `excluded_reason` в `config/niches.yaml`:
волна клонов одного сюжета про рога быка Брахмана (68% просмотров ниши),
забой скота, вердикт обложек unsafe, плюс сфабрикованные AI-«заводы».

**Языковой фильтр:** ролик остаётся в языке ниши только при совпадении трёх
условий — доля латиницы в заголовке ≥ 90%, `default_audio_language` пуст или
начинается с кода языка, langdetect по заголовку **вместе с описанием** даёт
нужный язык. По одному заголовку langdetect ошибается: замерено, 22 из 23
отбракованных так роликов оказались настоящим английским.

**Поиск:** основной бэкенд — yt-dlp (бесплатно), Data API остаётся только для
`videos.list` и `channels.list` по 1 unit. `search.list` за 100 units не
использовать без явной необходимости.

## Метрики и пороги (не менять без явного указания)

**День 21, по каждому из трёх каналов.** Пороги: CTR ≥ 4%, удержание на 30-й
секунде ≥ 60%, среднее удержание ≥ 40%. Считается пройденным, если порогам
отвечают **хотя бы 2 ролика из 5**.
- Прошёл — лучший по удержанию канал уходит в фазу 2.
- Ни один не прошёл — берём лучший по удержанию, меняем упаковку, снимаем ещё
  5 роликов.
- Не прошло дважды — новая тройка ниш либо закрытие направления.

**Неделя 12.** 1000 подписчиков и рост просмотров неделя к неделе — идём до
монетизации. Нет — закрытие.

**Что метрикой не является.** Просмотры на старте. Один выстреливший ролик —
повод ничего не менять до пятничного ревью.

**Темп (решение Евгения 2026-09-23).** Три ролика в неделю на каждый канал —
Why&How, Survivor's Notebook, The Case Room; личный Terms of Employment — два.
Итого одиннадцать роликов в неделю.

Замеренная себестоимость на текущем конвейере: объяснялка $14–29, дневник ~$21,
нуар ~$17; 96% суммы — генерация кадров. Одиннадцать роликов в неделю дают
**около $1000 в месяц против записанного бюджета $200–300**. Расхождение
известно и принято осознанно; рычаги снижения — меньше кадров на ролик,
переиспользование принятых кадров, возврат к локальной генерации, когда модели
подтянутся.

**Деньги.** Себестоимость ролика $10–20. Бюджет $200–300 в месяц.

## Монтаж и оживление кадров

Полные правила — `docs/montage_rules.md`. Жёсткое, нарушать нельзя:

- **Параллакс только DepthFlow** (`scripts/parallax_df.py`), своё не писать.
  Движение задаётся подклассом `DepthScene`, без него выходит статика.
  Проверять числом: разница первого и последнего кадра ниже 5 — движения нет.
- **Кадр перед анимацией берёт ту же картинку, что и клип**, и его проезд
  заканчивается в исходной точке. Иначе предмет в клипе возникает из ниоткуда.
- **Переходы:** перетекание 0.6 с по умолчанию (~90%), склейка только на
  переломе сюжета (~9%), затемнение только на границе акта. Замер референсов:
  Atlas One 0 склеек за 21 минуту, PLAN: ESCAPE 90% склеек.
- **Анимируем только смысловое движение** (речь, действие человека, движение
  среды как содержание) — около четверти кадров. Остальное статика с камерой.
  Где текст говорит «документов нет» — кадр стоит намертво.
- **Карточки и титры — Remotion** (`/home/chak/yt/motion`), не PIL.
- **В безлюдный кадр не подавать якорь героя и плиту с лагерем** — модель
  впишет их вопреки промпту. Нужны чистые плиты и явный запрет.
- **Тексты карточек сверять с брифом автоматически.** Модель выдумывает веса,
  номера, счета и строки дневника. На двух фильмах брак был в трети карточек.
- **Озвучка:** интонационные теги (не больше двух на реплику), ускорение 1.3
  с сохранением пауз (`scripts/voice_speed.py`). Хронометраж — из реального
  звука, не из оценки по словам в минуту.
- **Клипы Veo:** только image-to-video из утверждённой картинки; предмет в
  руках прописывать явно, иначе он отвяжется от человека.
- Порядок: озвучка → клипы → монтаж. Неверный кадр удалять сразу.
- Перед тем как писать своё, проверить готовое: на параллаксе это стоило часов.


## Публикация: решения по описаниям

- **Блок источников зависит от канала** (уточнено Евгением 2026-09-23).
  На развлекательных — Why&How, Survivor's Notebook, The Case Room — источников
  в описании **нет**: решение от 2026-09-14, блок читается как список литературы
  и отпугивает зрителя. Дисциплина фактов при этом сохраняется, она живёт в
  `brief.json` со ссылками.
  На личном канале **Terms of Employment источники в описании ставим**: там
  разбор построен на цифрах, и без ссылок он не работает. Строка «Sources in
  every description» остаётся убранной из описаний развлекательных каналов,
  чтобы канал не обещал того, чего не делает.
- **Про генеративную графику в описании не пишем.** Вместо этого в Studio
  ставится отметка об изменённом или синтетическом контенте: YouTube сам
  добавляет пометку, его формулировка суше нашей, дублировать не нужно.
- **Категория ролика — «Образование»**, одинаково на всех каналах: единый
  тематический сигнал важнее, чем подбор категории под конкретный выпуск.
  Замер референсов: Atlas One — Education, PLAN: ESCAPE — Entertainment,
  Blackfiles — Science & Technology, единого стандарта в нише нет.
- **Время публикации** сейчас почти не влияет: у канала без подписчиков нет ни
  уведомлений, ни ленты подписок. Замер шести хитов референсов: все будни,
  пять из шести с полудня до 20:00 по восточному времени США. Возвращаться к
  вопросу, когда появится график активности аудитории в Studio.


## Органический рост (замерено на первых трёх роликах)

Полностью — `docs/growth_notes.md`. Жёсткое, нарушать нельзя:

- **Платное продвижение не покупаем.** Ларсон: €50, 13 органических показов,
  ноль из рекомендаций. Ада: без рекламы, 41 показ, 53,8% из рекомендаций.

  было бы купить.
- **Пока подписчиков нет, в заголовке обязательна поисковая сущность** — имя,
  место, компания, год, сумма. Закон интриги снят с каналов, у которых есть
  показы в ленте; у нас единственная дверь — поиск, а загадка не ищется.
  Вернуться к интриге, когда пойдут показы в ленте.
- **Проверять конкурентное поле до производства:** `scripts/field_check.py`,
  минимум три формулировки запроса, вердикт по худшей. Один узкий запрос врёт:
  AAirpass показал 196k и «хорошее поле», по правильному запросу — 6,37M.
- **Ниша «человек обыграл систему» выработана.** Восемь проверенных тем, все
  заняты каналами-миллионниками. Искать свободную известную тему бессмысленно:
  конкурируем трактовкой — 20 минут реконструкции против их 6–11 минут
  закадрового текста поверх стока.
- **После каждой публикации смотреть «Контент, предлагающий это видео»** в
  разделе «Охват». Это соседство, куда YouTube поставил ролик. Аду поставил к
  бушкрафту — не тот смысл, отсюда CTR 2,4%. Не то соседство — править заголовок,
  первую строку описания и обложку.
- **Плохой клик хуже отсутствия клика.** Уход через 24 секунды говорит системе
  «не та аудитория». Честный заголовок, сужающий аудиторию, правильнее размытого.

**Учёт затрат обязателен.** Журнал `/mnt/nas/output/costs.jsonl`, отчёт
`python scripts/costs.py`. Замерено: две трети стоимости фильма — генеративное

## Ad-safety и честность

Правила обязательны для всех трёх каналов. Нарушение — брак, ролик не выходит.

**Обложки.** Правила формы и провокации — `docs/thumbnails.md`. Коротко: обложка
обязана задавать вопрос, а не отвечать на него (решение Евгения 2026-09-17,
описательные обложки не давали повода нажать). Четыре варианта на ролик, минимум
два приёмами «запрет / конфликт двух объектов / отрицание очевидной причины».
Обещание обложки закрывается в первую минуту ролика: клик с уходом на 24-й секунде
хуже отсутствия клика. Ограничения ниже при этом не снимаются ни ради какого CTR.

Никаких чужих лиц. Никаких логотипов СМИ и телеканалов. Никаких
имитаций эфирной графики: плашек «BREAKING», «LIVE», «1 MIN AGO», бегущих строк,
рамок новостных студий. Бренд обсуждаемой компании показываем **вордмарком,
нарисованным из названия** (стадия motion), а не скачанным файлом логотипа.

**Заголовки.** Ни одного утверждения, которого нет в `brief.md` со ссылкой на
источник. Формулировки вида «NASA Confirmed», «Scientists Just Proved»,
«Officials Admit» допустимы, только если ровно это есть в источнике. Гипотезу
называем гипотезой: «may», «could», «appears to» — не «confirmed».

**Содержание.** Без gore: ни крови, ни тел, ни кадров гибели людей. В
катастрофах фокус на инженерной причине отказа, а не на жертвах.

**Почему это правило, а не пожелание.** Ниша `industries_inside` была исключена
именно за это: волна клонов с забоем скота собирала миллионы просмотров и
получила вердикт unsafe. Трафик там был, денег бы не было.
